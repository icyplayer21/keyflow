# Keyflow {{VERSION}} — testing checklist

Tick what works, and note anything that doesn't (with a screenshot if you
can). Then send it back, together with your Mac model and macOS version.
**Settings ▸ About** shows the versions.

## Installation

- [ ] {{DMG}} opens and shows Keyflow and Applications
- [ ] Dragging Keyflow to Applications copies it
- [ ] Keyflow launches (after allowing it once in Privacy & Security)
- [ ] The Keyflow icon looks right in the Dock and in Finder

## Learn

- [ ] Lessons load, and the next exercise follows when one is finished
- [ ] The on-screen keyboard highlights the right key and finger (⌘K hides and shows it)
- [ ] Finger Focus: a finger and level can be picked, and rounds run
- [ ] Training progress is recorded (lesson stages advance, Progress shows it)

## Practice

- [ ] Typing works straight away, without clicking first
- [ ] Mistakes show in red; Delete and ⌥Delete correct them
- [ ] Accuracy and WPM look right for what you typed
- [ ] Tab or ⌘R restarts

## Test

- [ ] 30, 60 and 120 second tests run and stop on time
- [ ] The results show WPM and accuracy that match your typing
- [ ] Results appear in Progress

## Typing Mechanics

- [ ] Shift: using the wrong-side Shift is noticed
- [ ] Caps Lock: switching it on and off is detected, including when it is left on
- [ ] Capitalisation exercises (single capitals, all-caps words, the Lab) work
- [ ] Numbers & Symbols exercises work

## Progress

- [ ] Statistics appear after tests, practice and Learn rounds
- [ ] Quit Keyflow (⌘Q), open it again: history is still there

## Settings (⌘,)

- [ ] Every tab opens: General, Appearance, Typing, Training, Feedback, Data & Privacy, About
- [ ] Theme, font, size, caret and width change the typing screens
- [ ] The preview in Appearance can be typed into
- [ ] Changes are still there after quitting and reopening
- [ ] Data & Privacy ▸ Export… saves a JSON file
- [ ] About ▸ Send Beta Feedback… opens an email

## Stability

- [ ] No crashes (if it does crash, say what you were doing)
- [ ] No lost history or settings
- [ ] No serious display problems: overlapping text, blank screens, controls cut off
- [ ] Works in both Light and Dark Mode
